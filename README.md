We have opened [GitHub discussions](https://github.com/orgs/ismip/discussions) to deal with discussions, issues and questions about the [ISMIP7 protocol](https://www.ismip.org/research/ismip7-protocol).

To stay up-to-date with existing and new discussions, click on the watch button near the top of the  [documentation repository](https://github.com/ismip/documentation) and then select All Activity or Custom > Discussions (and Issues). You can then unsubscribe from any individual conversation if it is not relevant to you.
